# 수색 지도 원화와 지점 배치

v0.3.1의 지도는 프로젝트에서 직접 제작한 가상 지형도입니다. 외부 지도 서비스나 AI 이미지 생성은 사용하지 않았습니다. 실제 설악산의 측량·항법 지도와 구분하기 위해 게임 화면에도 개념도·거리 비례 아님을 표시합니다.

- 바탕 원본: `LastTransmission/Assets/Resources/Art/RescueTerrain-v1.png` (1600×900).
- 재생성: 저장소 루트에서 `node Tools/MakeMapTerrain.cjs`. Node 기본 모듈만 사용하며 다운로드·계정·별도 패키지가 필요하지 않습니다.
- 생성 요소: 가우시안 높이장과 파형으로 만든 가상 산세, 음영, 등고선, 침엽수 표기, 종이 입자와 접힘.
- 실제 경로·건물·이름표·출입 상세·선택 영역: `LastTransmission/Assets/Scripts/MapUI.cs`. 원문과 이름은 기존 `story.json`을 열어 표시합니다.
- Unity에서는 원본 크기와 등고선 선명도를 유지하도록 NPOT 변환·밉맵·텍스처 압축을 끕니다.

A 관제소와 C 대피소는 남쪽 임도로 연결합니다. 북쪽 다리의 옛 연결선은 붉은 점선과 붕괴 표시로 구분하며, 발전기 주계단의 낙석 구역과 철망 바깥 우회 보행로를 분리합니다. E 정비구는 관제소와 멀리 떨어진 산속 지점으로 그리지 않고, 30m 떨어진 독립 출입구를 보여 주는 별도 확대도에 배치합니다.

v0.4에서는 교신의 “노란 점선” 안내와 일치하도록 정비 보행로·범례·이름을 노란 황토색으로 맞췄습니다. 남쪽 임도는 녹색 실선, 통제·옛 연결선은 붉은 점선으로 구분합니다.

지도와 오른쪽 기록은 동시에 볼 수 있고, 긴 원문은 전체 폭으로 확대할 수 있습니다. 표시를 누르는 행위는 기존 문서를 열람하며 응답·구조·엔딩을 자동 선택하지 않습니다. 게임의 단서와 분기 데이터는 변경하지 않았습니다.

이 바탕과 생성 코드의 제작자는 본 프로젝트이며, 저장소의 MIT 라이선스를 적용합니다. 바탕 PNG와 소스는 상업 이용·수정·원본 재배포가 가능하며 MIT 고지를 유지해야 합니다. 외부 글꼴과 음향은 각 라이선스를 유지합니다.
