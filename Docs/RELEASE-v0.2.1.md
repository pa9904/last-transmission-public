# v0.2.1 — 버튼 클릭음 중첩 수정

공통 버튼 처리와 장치·상황판 처리에서 클릭음을 중복 호출했고, PlayOneShot으로 긴 효과음이 겹쳐 재생될 수 있었습니다.

- 메뉴, 문서 열기, 상황판 선택, 확인등 버튼의 클릭음을 제거했습니다.
- 쓰지 않는 computerNoise_003.ogg와 런타임 참조를 제거했습니다.
- 교신 송신, 출입 확정·승인 철회, 문밖 노크에만 효과음을 사용합니다.
- 효과음은 기존 재생을 멈추고 하나의 AudioSource에서 새 클립을 재생합니다. OneShot 음성을 누적하지 않습니다.
- 정기 노크는 다른 장치 효과가 재생 중이면 건너뜁니다. 효과별 작은 음량도 다음 프레임에 덮어쓰이지 않도록 유지합니다.

수정본은 기존 빌드와 분리한 `Builds/LastTransmission-0.2.1-Windows/`와 별도 ZIP으로 제공합니다. 실제 스피커 청취 평가와 코드·실행 검증은 구분하며, 검증 범위는 VERIFICATION.md에 기록합니다.
