# v0.4.0 UI 개편

무전·기록·상황판·출입 제어가 모두 같은 평면 버튼과 큰 본문 상자에 의존하던 화면을 장치와 서류의 역할에 맞게 정리했습니다.

- 무전은 왼쪽 수신기·주파수·대조 기록, 오른쪽 종이 교신 본문과 번호가 붙은 응답 영역으로 분리합니다.
- 금속 외함·나사·종이 입자·서류철·메모 표시·3회 확인등을 직접 그립니다.
- 진행 버튼은 황토색, 일반 조작은 회녹색, 위험한 결정은 적갈색으로 구분합니다. 호버·선택·비활성 상태와 버튼 글자 정렬을 통일합니다.
- 상단에 시간·현재 교신·예비 전원을 정리하고, 하단에는 여섯 장치의 아이콘·이름·단축키·현재 선택을 표시합니다. 관제실에서도 같은 메뉴로 장치에 접근합니다.
- 진행 안내는 관제실의 당직 메모에 표시합니다. 배경 소품의 설명은 마우스를 올렸을 때 나타납니다.
- 출입의 관측·확인등과 마지막 세 결정을 구분합니다. 최종 결정은 확인창을 거치며 Esc로 취소할 수 있습니다.
- 일시정지는 메뉴와 당직 기록, 엔딩은 근무 보고서, 여러 회차 엔딩 기록은 종이 보관철로 정리합니다.
- 지도, 모든 교신·단서·분기, 저장과 읽기 설정, 일반 버튼 무음을 유지합니다.
- 교신의 “노란 점선” 설명과 지도의 정비 우회로 색을 일치시켰습니다.
