# 크레딧

**마지막 교신 / Last Transmission**

게임 디자인, 한국어 이야기와 단서, Unity 코드, 지도·상황판·장치 UI, 절차적 환경음은 이 프로젝트를 위해 제작했습니다.

관제실 배경 원화: 프로젝트용 AI 생성 이미지, built-in image_gen 사용. 외부 무료 다운로드 에셋과 구분합니다. 원본·프롬프트는 [ART_PROMPTS.md](ART_PROMPTS.md)에 기록했습니다.

상황별 배경 음악 7편곡은 프로젝트에서 작곡하고 합성했습니다. 원본은 Tools/MakeScore.cjs에 있습니다.

이전 버전 장치 효과음 (v0.6에서 재생 종료): **Kenney — Sci-fi Sounds 1.0**, CC0 1.0. https://kenney.nl/assets/sci-fi-sounds

한국어 글꼴은 SUNN의 **SUIT Regular · Bold v2.0.5**입니다. SIL Open Font License 1.1. https://github.com/sun-typeface/SUIT/releases/tag/v2.0.5

Unity 엔진과 내장 모듈은 Unity의 조건을 따릅니다. 엔진 자체를 프로젝트 MIT 라이선스 대상으로 표시하지 않습니다.

원문 라이선스는 `LastTransmission/Assets/Resources/Fonts/SUIT-OFL.txt`와 `LastTransmission/Assets/Resources/Audio/Kenney-License.txt`. 상업 이용·재배포 기록은 [ASSETS.md](ASSETS.md)를 확인하세요.
