# v0.3.1 지도 개선

- 화면 위의 작은 점·선 도식을 넓은 종이 지형도로 교체했습니다.
- 등고선, 산림, 계곡, 접힌 종이, 관제소·대피소·발전기 실루엣을 직접 제작했습니다.
- 남쪽 임도, 정비 우회로, 붕괴·낙석 통제 경로를 서로 다른 선으로 구분하고 범례를 넣었습니다.
- 북쪽 다리 붕괴 표시와 경로의 연결 관계를 정리했습니다.
- 관제소와 30m 떨어진 동쪽 정비구는 출입 상세 확대도로 표현합니다.
- 지점·이름표와 오른쪽 목록으로 원문을 확인하고, 긴 기록을 전체 폭으로 확대할 수 있습니다. M·Esc로 지도로 돌아옵니다.
- 원문·응답·구조 인원·엔딩 조건과 기존 저장은 유지합니다. 일반 버튼 클릭음도 추가하지 않았습니다.

새 지형도는 프로젝트가 직접 작성한 코드로 생성하며 무료 외부 에셋이나 외부 패키지를 추가하지 않았습니다. [원화·재생성·라이선스](MAP_ART.md), [실제 검증 범위](VERIFICATION.md)를 제공합니다.
