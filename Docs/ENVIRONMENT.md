# 개발 환경

- Unity 6000.6.7f1 및 Windows Standalone Build Support
- Windows x64 Mono, Unity 내장 렌더링 및 IMGUI
- 외부 UPM 패키지 없이 Unity 내장 모듈 사용. 버전은 ProjectSettings와 Packages에서 확인할 수 있습니다.
- PowerShell 7에서 Tools/Build.ps1을 실행합니다. Unity 설치 위치를 지정하려면 -EditorPath를 사용합니다.
- Windows 빌드는 GitHub Releases에서 다운로드할 수 있습니다.
