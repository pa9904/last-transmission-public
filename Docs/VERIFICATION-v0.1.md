# 실제 검증 기록 — v0.1.0

날짜: 2026-11-11 (Asia/Seoul). Windows x64, Unity 6000.6.7f1, AMD Radeon RX 7800 XT. 이 문서는 실행한 항목과 미검증 항목을 구분합니다. Steam 출시 가능 판정이 아닙니다.

## Unity와 핵심 규칙

실제 Unity Editor를 배치 모드로 열어 에셋을 import하고 C# 컴파일, 씬 생성, Windows x64 Mono 빌드를 실행했습니다. 결과 `LAST_TRANSMISSION_BUILD Succeeded`. 소스 프로젝트에는 씬·Resources·글꼴·음향·모든 필요한 .meta와 패키지 잠금 파일이 포함됩니다.

`Verification.Run()` 결과:

- **35,023 assertions 통과**
- 교신 6건의 응답 조합 **729개**
- 각 조합의 최종 출입 3개, **2,187개 분기**
- 도달한 엔딩: 열린 문 729 / 응답 없는 아침 1,377 / 마지막이 아닌 교신 81
- 문서·주파수·마지막 페이지 확인 전 응답 차단
- 각 선택·교신 전환 상태의 유효성, JSON 왕복
- 실제 파일 저장과 불러오기, 잘못된 저장의 백업 복구, 잘못된 교신/단계 거절
- 설정 저장 복원, 필수 한국어 글꼴·3개 OGG 파일 로드

로그: `Artifacts/unity-build.log`. 요약: `Artifacts/Verification/editor-report.txt`. 로그와 생성 파일은 Git 관리 제외.

## 실행 파일 검증

실제 빌드한 `LastTransmission.exe`를 창을 띄운 상태로 실행했습니다. 별도 QA 프로필로 게임의 실제 진행 메서드를 호출한 자동 검증입니다. 마우스로 모든 조합을 플레이한 결과라고 표현하지 않습니다.

- 모든 교신의 조사 조건 → 선택 → 결과 → 다음 교신
- 좋은 경로 전체 진행과 정비구 엔딩
- 다른 경로 전체 진행 후 정문 개방 엔딩과 전체 잠금 엔딩
- 진행 저장의 실제 파일 왕복
- 별도 새 프로세스에서 **교신 4 시작 지점** 이어하기
- 새 프로세스에서 전체 음량 0.32, 눈보라 끄기 등 설정 복원
- 실제 프레임 진행, 한국어 글리프 존재
- 타이틀, 지도, 교신, 최종 출입, 3개 엔딩의 PNG 캡처

확인한 화면: 1600×900 (16:9), 1280×800 (16:10). 배율 변화 후 그래픽 선 위치가 틀어지는 문제와 긴 엔딩 본문의 잘림을 수정했습니다. 긴 교신·기록·엔딩은 스크롤 영역을 사용합니다. 최대 교신 본문 높이는 약 311 기준 픽셀이며 241 픽셀 영역에서 스크롤 가능합니다.

처음의 숨김 실행은 OnGUI 렌더링이 생략되고 스크린샷이 실패했으므로 화면 검증 결과에서 제외했습니다. 스크립트를 수정해 렌더링·캡처 누락을 실패로 처리하고, 보이는 게임 창에서 다시 실행해 통과했습니다.

결과와 캡처: `Artifacts/Player-1600x900/`, `Artifacts/Player-1280x800/`. 두 해상도 모두 최종 바이너리에서 PLAYER_VERIFICATION_PASS와 RESUME_VERIFICATION_PASS를 확인했습니다. 각 폴더의 player-report.txt, ResumeProfile/resume-report.txt를 확인할 수 있습니다. 타이틀 최종 캡처는 `Docs/Screenshots/title.png`에도 포함됩니다.

## 실제 UI 조작

Windows computer-use로 첫 교신 버전을 직접 조작했습니다:

- 타이틀 → 새 게임 → 안내 → 관제실
- 지도·근무 기록 열기, 한국어 표시
- 무전기 수신, Space로 다음 문장과 즉시 표시
- 단서 확인 후 선택지 등장, 구조 경로 응답
- 결과 → 최종 출입 → 확인창 → 임시 엔딩

전체 버전 1280×800 창에서도 실제 UI를 추가 조작했습니다:

- 타이틀의 이어하기 → 저장된 교신 4 지점 복원
- 주파수를 91.2 → 83.4 MHz로 바꿔 잡음 화면에서 수신 본문으로 전환
- 설정 슬라이더로 전체 음량 32% → 69%, 텍스트 75 → 26자/초 변경
- 저장된 JSON의 master 0.6875, textSpeed 약 25.76을 확인
- H로 이전 교신과 선택 결과 다시 읽기, 마우스 휠로 본문 스크롤
- Esc로 장치 닫기 → 다시 Esc로 일시정지 → 저장 후 타이틀
- 기존 진행이 있을 때 새 게임 확인창이 나타나고 취소가 동작
- 게임 내 크레딧 표시와 창 종료

이 UI 확인은 별도 Artifacts/ManualProfile 저장을 사용했습니다. 최종 배경의 그라데이션 경계와 눈보라 그리기를 추가 보정한 뒤 빌드와 자동 검증을 다시 수행했습니다. 1600×900과 1280×800 캡처에서 타이틀·지도·출입·엔딩의 배치와 한국어를 직접 확인했습니다.

## 미검증·출시 전 작업

- 외부 사람이 처음 플레이한 20~30분 분량, 난이도, 단서 이해도는 측정하지 않았습니다. 자동 검증 소요 시간은 플레이 시간이 아닙니다.
- 소리가 로드되고 재생 소스가 구성된 것은 확인했지만, 실제 헤드폰·스피커에서 전체 믹스를 청취하고 균형을 평가하지 않았습니다.
- 다양한 저사양 PC·그래픽 드라이버·DPI·다중 모니터·울트라와이드 환경, 성능 목표, 장시간 플레이는 별도 검증 필요.
- 전체 화면 토글은 구현되어 있으나 기기별 전환 안정성은 추가 확인 필요.
- Steam SDK, 업적, 클라우드, 스토어 제출, 코드 서명, 외부 QA는 이번 버전 범위에 포함하지 않았습니다.
