# v0.2.0 변경 기록

v0.1은 타이틀부터 엔딩까지 동작했지만, 문서 열람과 응답 버튼에 조작이 집중되어 있었습니다. v0.2에서는 단서 해석과 최종 신원 확인을 실제 입력 단계로 보강했습니다.

- **상황판:** 교신마다 위치·시간·규정·장치 상태를 대조하는 판단 근거 두 가지, 총 12개를 기록합니다. 근거 문서를 바로 열고 이전 판단을 복기할 수 있습니다.
- **오판 피드백:** 틀린 해석도 기록할 수 있으며 송신 후 원문과 비교하는 설명이 남습니다. 실제 경로·응답이 구조 결과를 결정합니다.
- **확인등:** 답변 한 번으로 신원이 자동 승인되지 않습니다. 두 색을 섞어 세 번 표시하고 출입구별 보고를 직접 비교합니다. 잘못된 관측은 잠금을 해제하지 않습니다.
- **이전 선택의 영향:** 정문 사전 승인이 누적됐다면 마지막에 직접 철회해야 정비구의 안전한 개방이 가능합니다.
- **관제실:** 프로젝트용 생성 원화와 실제 장치 클릭 영역, 상황판·표시등·선택에 따른 회선 상태를 연결했습니다. 생성 출처와 프롬프트를 별도로 기록했습니다.
- **저장:** 판단 근거, 표시한 색과 관측 승인, 사전 승인 철회를 저장합니다. v0.1 저장의 완료된 교신과 엔딩은 보존합니다.
- **배포:** Windows x64 빌드, 라이선스·크레딧·검증 기록, 소스 커밋과 빌드 파일 해시를 포함합니다. v0.1 ZIP은 별도로 보존합니다.

현재 콘텐츠는 교신 6건, 문서 12개, 엔딩 3종입니다. 초회 20~30분은 목표이며 실제 사람 대상 플레이 시간·재미·난이도와 음향 믹스 평가는 남아 있습니다. Steam 출시 판정은 아닙니다. 정확한 실행 검증 범위는 [VERIFICATION.md](VERIFICATION.md)를 확인하세요.
