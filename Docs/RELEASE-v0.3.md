# v0.3.0 변경 기록

문서를 다시 찾거나 장치를 닫고 여는 데 반복되던 조작을 줄이고, 읽기와 회차 기록을 보강했습니다. 이야기의 정답과 기존 엔딩 조건은 유지합니다.

- 관제실의 다음 할 일 카드와 N 키가 현재 필요한 교신·원문·상황판·출입 장치로 안내합니다. 정답이나 응답을 자동으로 선택하지 않습니다.
- 장치 화면 아래에서 무전·지도·근무 기록·상황판·교신 기록·출입 제어로 바로 이동합니다.
- 지도와 근무 기록을 오가도 마지막 문서와 읽던 스크롤 위치를 실행 중 기억합니다. 같은 문서를 다시 눌러도 위치가 초기화되지 않습니다.
- 교신 기록을 6개 탭으로 나눠 이전 대화와 당시 판단·결과를 찾아 읽습니다. 미래 교신 탭은 잠겨 있습니다.
- 읽기 설정에 본문 크기 100~130%, 교신 즉시 표시를 추가했습니다. 즉시 표시에서는 Space 한 번으로 다음 페이지로 넘어갑니다.
- 전체·효과음 외에 바람과 무전 잡음의 독립 음량을 제공합니다. 조절 막대와 손잡이를 또렷하게 표시합니다. 일반 버튼 클릭음은 계속 없습니다.
- 엔딩 보관철은 확인한 결말만 제목과 본문을 열어 줍니다. 새 근무로 이어하기를 교체해도 보관철은 유지되고, 이전 버전의 완료된 이어하기도 가져옵니다.
- 설정·크레딧·엔딩 기록을 닫으면 열었던 메뉴로 돌아갑니다. 게임 창에서 벗어나면 저장하고 일시정지합니다.
- 이전 진행과 기존 음량·읽기 속도 설정을 보존하며 새 항목은 기본값으로 이관합니다.

새 외부 에셋이나 패키지는 추가하지 않았습니다. 기존 원화·나눔고딕·Kenney 장치음의 라이선스는 [ASSETS.md](ASSETS.md)에 유지합니다. 변경된 조작은 메모장용 v0.3.0 공략과 배포 폴더의 시작하기.txt에 반영합니다.

실제 실행 검증 범위와 남은 한계는 [VERIFICATION.md](VERIFICATION.md)를 확인하세요. 사람의 초회 플레이 시간과 음향 청취 평가는 아직 완료하지 않았습니다.
